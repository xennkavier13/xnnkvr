# xnnkvr OS — Macintosh System 1–6 Personal Portfolio

Personal portfolio of **Kenn Xavier Dabon (`xnnkvr`)** reinterpreting the monochrome 1-bit pixel aesthetic of early Apple Macintosh (System 1–6) with Next.js, Tailwind CSS, and Framer Motion.

## Getting Started

```bash
npm install
npm run dev
```

Open `http://localhost:3000` in your browser.
